云端部署文件已提供：[部署说明](deploy/云端部署说明.md)。[打开 Render 配置部署入口](https://render.com/deploy?repo=https://github.com/719566486/yingke-aigc-studio)。后台保留可灵、Kokoro 中文配音和 FFmpeg 合成，使用云服务器 CPU，无需本机在线。配置为持续运行的收费服务，实际费用由云平台展示并由你确认。

当前分享链接只有在云服务器开通、真实预演通过并切换入口后，才能在本机关机时继续创作。部署文件本身不代表已开通服务器。四种风格卡片使用本地保存的授权参考图片，可查看大图及来源；参考图片不自动上传给模型。

## 对外分享

固定体验入口：https://719566486.github.io/yingke-aigc-studio/

源码仓库：https://github.com/719566486/yingke-aigc-studio

这个版本由 GitHub Pages 提供固定入口，由你的 Windows 电脑运行配音、视频剪辑与生成队列。双击「启动分享.cmd」后保持电脑开机、联网且不休眠，别人即可通过固定网址进入。双击「停止分享.cmd」关闭对外连接；管理员工作台 http://127.0.0.1:8787 继续仅在本机使用。

访客连接与管理员工作台是两个独立入口。访客不能读取或修改服务配置，只能访问自己会话创建的图片与作品。首版每个浏览器会话在滚动24小时内最多创建1个AI视频、3个免费预演，全站同期最多接受10个AI任务。清除浏览器记录会建立新会话，所以它不是实名人数限制；全站上限独立生效。已提交但结果未知的任务也占用预留额度，避免绕过费用上限。访客仍需明确确认生成及素材发送。

公开连接优先使用本机已安装的官方 cloudflared 工具，未安装或连接失败时使用 Windows 自带 SSH 工具连接 localhost.run。临时地址可能在重连后变化；分享进程会自动更新 GitHub 入口配置，入口优先读取最新连接信息。电脑关机、网络中断或分享进程关闭期间，固定入口会显示暂未开启服务。本版本不是独立的24小时云服务器部署。

可选的官方 cloudflared 程序放在 work/tools/cloudflared.exe 或通过 STUDIO_CLOUDFLARED 指定。它不进入源码仓库，官方下载地址为 https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe 。没有该程序时仍可使用 SSH 备用连接。

GitHub只上传应用源码、测试和访问入口文件。data、work、.venv、outputs、API密钥、数据库、用户图片及成片均不上传。访客点开分享网址即可直接进入，无需输入体验码。系统自动为每个浏览器建立独立会话并限制生成额度。密钥仍由本机Windows用户加密保护。

新的电脑需要先建立Python环境并配置本地配音与FFmpeg，再在管理员工作台填写自己的服务凭证；源码本身不包含原电脑的任何凭证。

这是运行在本机的创作平台首版，网页和后台均位于 D:\workspace\AIGC创作平台。

## 开始使用

双击「启动平台.cmd」，在浏览器打开 http://127.0.0.1:8787 。使用完双击「停止平台.cmd」。

1. 输入一句创意，选择风格、画幅和旁白，可选上传参考图。
2. 生成三镜头分镜，逐镜修改旁白和画面描述。
3. 选择本地分镜预演，生成 15 秒、720p、24fps、带中文配音与字幕的 MP4。
4. 在右侧播放，下载 MP4、封面、字幕和分镜。作品可在「我的作品」中继续访问。

本地分镜预演使用程序绘制的画面或用户参考图，画面不由 AI 生成。配音使用已有 Kokoro，本地 FFmpeg 完成合成。默认不向第三方发送创意或图片。

## 连接 AI 视频

在网页左下角「服务配置」中填写可灵开发者平台创建的一个 API Key，保存后点击只读认证检查。无需另找 AccessKey / SecretKey。旧版 AK/SK 位于折叠兼容设置中，已有凭证仍可使用；同时填写时优先使用 API Key。网页会员、Codex 插件登录与开放平台凭证不同，不能互换。

首版使用 API Key 的 Bearer 认证，兼容官方仍保留的 v1 文生视频和图生视频接口，默认 API 地址 https://api-beijing.klingai.com/v1，模型 kling-v3。国际区示例地址为 https://api-singapore.klingai.com/v1。服务地区请以创建该 API Key 的开发者控制台示例为准。地区、模型和档位必须与你开通的 API 权限一致。15 秒请求需要支持该时长的模型。参考图会在本机按所选画幅居中裁剪，再发送给可灵。

认证检查只查询任务列表，不提交付费生成。每次 AI 视频任务仍需在制作页明确勾选费用及素材发送确认。模型任务包含生成费用，API 状态和画质须在真实账号下联调确认。2026年10月27日已完成一次真实可灵文生视频联调：15秒标准档竖屏，首个成片约185秒；图生视频与AI编剧不在本次真实测试范围。

可选配置 OpenAI 兼容文本接口的 base URL、模型名和 API Key；勾选 AI 编剧并确认外发后，创意才发送给该服务。未配置时使用本地模板分镜。模型名不预设为用户未开通的版本。

## 运行与数据

- Python FastAPI + 原生 HTML/CSS/JS，避免另装前端构建工具。
- SQLite 保存任务和真实处理阶段，单工作线程限制 GPU 及本地合成负载，最多 4 个活动任务。
- 支持刷新恢复和原任务继续查询；不把轮询超时当作重新扣费的依据。
- 已开始提交但没有任务号时，状态标为「待核对」，必须先查可灵控制台，填回原任务号后继续查询。
- 密钥以 Windows DPAPI 加密，保存在 data/settings.json；只可由相同 Windows 用户解密。密钥不会通过接口返回浏览器。
- 作品在 data/jobs，参考图在 data/uploads，日志和依赖缓存在 work；请勿提交 data、work 或 .venv 到版本库。
- 默认已完成、失败或取消任务在 72 小时后自动清理。待核对及暂停任务保留供对账；参考图在无存活任务引用且超过留存时间后清理。
- 管理员后台仅绑定 127.0.0.1:8787；启动分享后，独立访客网关通过加密公网连接开放，单工作线程按队列处理任务。
